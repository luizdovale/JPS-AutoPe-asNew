# 🚚 JPS Auto Peças Diesel  
### **Site institucional moderno e profissional**

🔗 **Site oficial:** https://jpsautopecas.vercel.app/

Projeto de site desenvolvido para a **JPS Auto Peças**, empresa com forte atuação no mercado automotivo, especializada em **peças, serviços e soluções para toda a linha diesel**.

> **“Há mais de 25 anos atendendo com excelência toda a linha diesel.”**

---

## 📌 Sobre o Projeto

Este site foi pensado para transmitir:

- Credibilidade  
- Tradição  
- Profissionalismo  
- Modernidade  
- Força visual automotiva  

Com foco em uma **experiência visual impactante**, layout clean e moderno, imagens realistas e comunicação direta com o cliente via **WhatsApp**.

---

## 🎯 Objetivos do Site

- Fortalecer a presença digital da JPS Auto Peças  
- Apresentar produtos e serviços da linha diesel  
- Gerar contatos diretos via WhatsApp  
- Transmitir confiança através da história de mais de 25 anos no mercado  
- Utilizar identidade visual moderna e profissional  

---

## 🧱 Estrutura do Site

- **Home**
  - Hero com imagem realista
  - Destaque institucional (25+ anos)
  - Cards de serviços
  - Avaliações de clientes (estilo Google)

- **Serviços**
  - Mecânica diesel
  - Troca de óleo
  - Manutenção e reparos
  - Serviços especializados na linha diesel

- **Catálogo**
  - Peças diesel
  - Filtros
  - Óleos
  - Mangueiras
  - Componentes de motor

- **Sobre Nós**
  - História da empresa
  - Imagens realistas
  - Tradição e confiança

- **Contato**
  - Formulário com envio direto para WhatsApp
  - Botão flutuante do WhatsApp
  - Mapa de localização

## 🎨 Identidade Visual

| Uso | Cor |
|----|----|

| Branco | `#FFFFFF` |
| Cinza claro | `#F7F7F7` |
| Preto | `#1B1D24` |
| WhatsApp | `#25D366` |

### Tipografia
- **Logo tipográfica:** Anton  
- **Textos gerais:** Inter / Montserrat / Poppins  

A marca **JPS** é representada de forma tipográfica, forte e industrial, sem uso de imagem de logo tradicional.

---

## 🧠 Imagens

- Todas as imagens do site são **geradas por IA**
- Estilo **realista automotivo**
- Alta resolução (mínimo 2048px)
- Totalmente alinhadas com cada seção do site
- Sem imagens genéricas ou minimalistas

## 💬 Contato via WhatsApp

O site possui:
